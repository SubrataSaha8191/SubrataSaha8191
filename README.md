## `01 / About me and current focus`

I approach engineering by moving beyond prototypes into working, dependable systems:

- **Artificial Intelligence & Machine Learning:** Developing data-driven pipelines, feature extraction workflows, and applied machine learning models tailored for real-world inference.
- **Data Science & Intelligent Agents:** Designing autonomous agent workflows, contextual telemetry aggregation, and decision-support engines that process multi-source inputs.
- **Cybersecurity & Security Automation:** Exploring proactive threat detection, URL and phishing classification, and automated security monitoring designed to reduce operational attack surfaces.
- **Backend Engineering & Rust-Powered Automation:** Architecting low-latency APIs with FastAPI and exploring Rust to engineer high-throughput, memory-safe tooling and robust automation services.
- **Production-Oriented Systems & Practical Engineering:** Translating conceptual algorithms into containerized, testable services using Linux, Docker, and CI/CD best practices.
